# Estudio 360

Synthetic profile and original SVG artwork for trying the editor and reproducing documentation screenshots. No real account or follower data is included. Copyright (c) 2026 Juan Peressa and contributors, MIT; see the root LICENSE.

Import `studio360.json` through the editor's project settings. The `art/` files are the editable original vectors; regenerate the backup with `node scripts/create-example.cjs`.

Screenshots in `docs/screenshots/` show this example in Chrome at desktop and mobile browser sizes. They are screenshots of Instagram 360, not captures of the native Instagram app.
