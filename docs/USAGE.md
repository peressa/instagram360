# Usar Instagram 360

Abrí [la demo](https://ig360.peressa.dev). No hace falta iniciar sesión ni conectar una cuenta.

1. Tocá **Fotos**, subí imágenes y arrastralas al perfil. También podés tocar una miniatura para agregarla.
2. Tocá el nombre, usuario, bio o cifras para escribir. El valor completo de las cifras aparece al editar. Enter termina los campos de una línea; Esc restaura la edición anterior.
3. Tocá el avatar o una portada para cambiar su imagen. Arrastrá dentro del círculo para encuadrar; pellizcá o usá +/− con el círculo enfocado para acercar.
4. Cambiá entre **iPhone, Android, PC, tablet o web móvil** con el selector flotante.
5. Abrí una publicación o destacado para recorrer la propuesta. Las interacciones son simuladas y locales.
6. Usá **Exportar** para descargar una captura del perfil o las imágenes de la grilla.

Los tres puntos del perfil abren las herramientas: apariencia, publicaciones, propuestas, importación y respaldos. El mockup sigue siendo el espacio principal.

## Carruseles y destacados

En **Fotos**, seleccioná imágenes con los círculos y arrastrá el grupo a una publicación para agregarlas al carrusel. El orden de selección marca el orden de agregado; Shift selecciona un rango en PC. Si soltás sobre un casillero vacío, creás un solo carrusel. Las fotos que ya están en esa publicación no se duplican.

Abrí la publicación y tocá **Fotos · n** sobre la imagen: arrastrá las miniaturas para ordenar; la primera es la portada de la grilla. En celular, mantené pulsada una miniatura y arrastrala. Con teclado, enfocá una miniatura y usá Alt + ←/→. El **+** abre la biblioteca sin cerrar la publicación: arrastrá las fotos a la imagen o a una miniatura para insertarlas antes. También podés usar **Agregar a esta publicación** con la selección hecha. Quitar una foto del carrusel la mantiene en la biblioteca. Cada agregado en grupo se puede deshacer como un solo cambio. Se conserva la edición desde los tres puntos para cargar archivos directamente. En PC usá las flechas de la imagen; en celular deslizá horizontalmente. Las flechas exteriores de PC cambian de publicación, las interiores cambian de foto. El ZIP incluye las portadas y una carpeta `carousel_XX` con la secuencia completa, ajustada sin recortar a la proporción de exportación.

El botón de reproducción de cada destacado abre sus historias. Tocá a los lados, deslizá o usá las flechas para avanzar/retroceder. La pausa conserva el progreso; mantener pulsada la imagen pausa hasta soltar. Al volver a la pestaña se respeta una pausa manual. Los destacados vacíos se omiten al navegar. Arrastrá una o varias fotos desde **Fotos** al círculo de un destacado para agregarlas a su secuencia. Dentro del visor, **Historias · n** muestra miniaturas: arrastralas para ordenar, tocalas para verlas o usá **×** para quitarlas. En celular, mantené pulsada la miniatura y arrastrá; con teclado, usá Alt + ←/→. El **+** abre la biblioteca sin salir del visor: soltá las fotos sobre la historia para agregarlas al final o sobre una miniatura para insertarlas antes. También está **Agregar a este destacado**. La reproducción se pausa durante la edición y conserva tu pausa manual al terminar. La portada existente mantiene su imagen y encuadre; un destacado sin portada toma la primera foto agregada. Los duplicados se omiten. Quitar una historia conserva la foto en la biblioteca; podés vaciar el destacado y volver a cargarlo. Los tres puntos siguen disponibles para subir archivos directamente. Al terminar la última secuencia se vuelve al perfil.

## Ejemplo

Descargá [studio360.json](../examples/studio360.json) desde GitHub (Download raw file). Abrí los tres puntos → **Proyecto y ajustes → Importar** y elegí ese archivo. Se crea una propuesta nueva. Incluye gráficos originales y datos ficticios, reutilizables bajo MIT.

## Guardado y cambio de dirección

Los perfiles se guardan en este navegador y dominio. Para moverlos, abrí las herramientas → **Guardar respaldo** en la dirección anterior; luego **Importar** en la nueva. Repetí para cada propuesta. Borrar los datos del navegador puede eliminar proyectos y fotos; conservá los JSON descargados.

Los respaldos anteriores siguen siendo compatibles. Incluyen fotos y comentarios simulados: guardalos como documentos personales, no como reportes públicos de errores.

## Alcance

No publica en Instagram ni envía mensajes reales. Reels/videos usan portadas estáticas. Las variantes de dispositivo son maquetas: no se certifica coincidencia con todas las versiones de las apps. Los contadores usan las muestras web documentadas; el corte exacto 9999/10000 y las abreviaturas nativas de Android siguen pendientes.

## English quick start

Use **Fotos** to upload images, drag into the grid and click profile fields to edit. The floating selector changes devices; **Exportar** downloads the result. The three-dot menu contains settings and **Guardar respaldo / Importar** (backup/import). Projects stay in your browser. The interface is Spanish; English contributions are welcome.
